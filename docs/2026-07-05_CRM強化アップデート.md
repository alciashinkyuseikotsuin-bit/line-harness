# 2026-07-05 CRM・エンゲージメント強化アップデート

コンサル堀の公式LINE運用（顧客管理・教育・エンタメ・個別分析・個別配信）のための大型アップデート。

## 🚀 反映手順（2ステップ・必須）

### 1. Supabase でSQLを実行（DBに新テーブルを作る）
1. https://supabase.com/dashboard → 該当プロジェクト → SQL Editor
2. `migrations/006_crm_engagement.sql` の中身を全部コピーして貼り付け → Run
3. 「Success」と出ればOK（何度実行しても安全な書き方になっています）

### 2. Vercel に ANTHROPIC_API_KEY を追加（AI分析を使う場合）
1. https://console.anthropic.com/ でAPIキーを発行
2. Vercel → line-harness → Settings → Environment Variables
3. `ANTHROPIC_API_KEY` = `sk-ant-...` を追加 → Redeploy
4. ローカル開発するなら `.env.local` にも同じ行を追加

※キー未設定でもAI以外の全機能は動きます（AI分析ボタンを押すと案内が出るだけ）。

## 📋 追加された機能

### 顧客管理（CRM）
- **顧客カルテ** `/bot/users/{id}`: プロフィール・ステージ管理（新規→興味あり→教育中→見込み→商談中→顧客→VIP→休眠）・タグ・メモ・行動タイムライン（送受信メッセージ＋イベント）・アンケート回答履歴・ポイント履歴
- **1:1送信**: カルテ画面から個別メッセージを送信（確認ダイアログ→手動実行のみ）
- **友だち一覧強化**: 検索・ステージフィルタ・スコア/ポイント列・行クリックでカルテへ

### データ収集（全部自動で貯まる）
- 送受信メッセージ全記録（`messages`）
- 行動イベント全記録（`friend_events`）: 友だち追加・回答・クリック・おみくじ等
- **リンククリック計測** `/engage/links`: 計測リンクを作成→配信文に `{link:コード}` と書く→誰がクリックしたか記録＋タグ・ポイント自動付与

### 一人一人の分析
- **エンゲージメントスコア（0-100）**: 直近のアクティブ度・メッセージ数・回答数・クリック数から自動計算。ホット/アクティブ/ライト/休眠の4バンド
- **AI人物分析**: カルテの「AI分析を実行」→ 人物像サマリー・興味関心・温度感・おすすめアプローチ・次の一手・その人向け配信文サンプルを生成（Claude API使用）

### その人に合わせた配信
- **差し込み変数**: 配信文に `{name}` `{points}` `{stage}` を書くと1人ずつ置き換えて送信（全配信経路対応: 一斉・セグメント・予約・ステップ）
- **AI配信文生成API**: `/api/ai/draft` に目的とターゲットを渡すと配信文ドラフトを生成

### 楽しませる機能
- **キーワード自動応答** `/engage/replies`: 特定ワードに自動返信＋タグ＋ポイント。「1人1回だけ」設定で隠しワードキャンペーンも可能
- **おみくじ**: 友だちが「おみくじ」と送ると1日1回、運勢＋経営ワンポイントを返す。項目は `/engage/omikuji` で編集（サンプル5件入り）
- **ポイント・特典** `/engage/points`: 回答・クリック・おみくじ・デイリーメッセージでポイント自動付与。◯pt到達で特典メッセージ＋タグを自動送付。友だちは「ポイント」と送ると残高確認。ランキングも表示
- **診断コンテンツ**: アンケート作成画面で「診断」を選ぶと、タイプ定義＋選択肢ごとの加点を設定可能。全問回答すると診断結果（例:「あなたは攻め型サロン経営者」）を自動送信＋タグ付け→そのタグでステップ配信（教育）に自動接続

## ⚙️ 仕組みメモ

- ポイント付与ルールは `/engage/points` で変更可能（DB: `app_settings.point_rules`）
- スコアは受信・回答のたびに自動再計算。ダッシュボードの「スコア再計算」で全員一括も可
- AIモデルは環境変数 `AI_MODEL` で変更可（デフォルト: claude-opus-4-8）
- 計測リンクのベースURLは `APP_BASE_URL`（未設定ならVercelの本番URLを自動使用）
- 予約配信・ステップ配信の実行は従来通り `/api/broadcast/process` `/api/step-flows/process` を外部cron（cron-job.org等）で叩く構成

## 🔒 変わっていないこと（安全性）
- 自動でLINE配信を始める機能はない。配信は今まで通り管理画面から手動実行
- 既存のアンケート・ステップ配信・リッチメニュー等の挙動は維持
- LINE公式アカウント（manager.line.biz）の設定には一切触れていない
